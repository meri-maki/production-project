# Лайвкодинг задачи для Frontend Middle разработчика

Этот репозиторий содержит 3 задачи для лайвкодинга с компонентами React, содержащими различные ошибки. Все компоненты используют TypeScript, React и SCSS modules.

## Структура задач

### 📁 task1-user-card/
**UserCard Component** - Карточка пользователя с информацией и действиями
- Компонент: `UserCard.tsx`
- Стили: `UserCard.module.scss`
- Сложность: ⭐⭐⭐

Основные проблемы:
- Обработка отсутствующих данных
- Утечки памяти
- TypeScript ошибки
- Проблемы доступности

### 📁 task2-todo-list/
**TodoList Component** - Приложение для управления задачами
- Компонент: `TodoList.tsx`
- Стили: `TodoList.module.scss`
- Сложность: ⭐⭐⭐⭐

Основные проблемы:
- Неправильные типы данных
- Логические ошибки
- Проблемы производительности
- React анти-паттерны

### 📁 task3-search-autocomplete/
**SearchAutocomplete Component** - Поиск с автодополнением
- Компонент: `SearchAutocomplete.tsx`
- Стили: `SearchAutocomplete.module.scss`
- Сложность: ⭐⭐⭐⭐⭐

Основные проблемы:
- Race conditions
- Утечки памяти
- Проблемы с регулярными выражениями
- Доступность и UX

## Как использовать

1. Выберите одну из задач
2. Откройте соответствующую папку и изучите README.md с описанием ошибок
3. Попросите кандидата найти и исправить указанные проблемы
4. Обсудите возможные улучшения и оптимизации

## Критерии оценки

- **Понимание проблемы** - насколько быстро кандидат находит ошибки
- **Качество решения** - правильность и элегантность исправлений
- **TypeScript** - корректное использование типов
- **React best practices** - следование современным практикам
- **Производительность** - понимание оптимизаций
- **Коммуникация** - объяснение решений и рассуждений

- Задача 2: 30-40 минут
- Задача 3: 40-50 минут
