# Лайвкодинг задачи для Frontend Middle разработчика

Данный репозиторий содержит 3 задачи для проведения лайвкодинга с кандидатами на позицию Frontend Middle разработчика.

## Технологии
- TypeScript
- React
- SCSS Modules

## Формат проведения
Кандидату предоставляется компонент с ошибками, который нужно исправить. Время выполнения каждой задачи: 20-30 минут.

---

## Задача 1: UserCard компонент

**Файлы:** `task1-usercard/UserCard.tsx`, `task1-usercard/UserCard.module.scss`

**Описание:** Компонент карточки пользователя с возможностью отображения деталей.

### Ошибки в TypeScript/React:
1. **Ошибка 1:** Использование `any` вместо типизации для `userDetails`
2. **Ошибка 2:** Отсутствует обработка ошибок в fetch запросе
3. **Ошибка 3:** Отсутствует `user.id` в зависимостях useEffect
4. **Ошибка 4:** Не проверяется наличие email перед открытием mailto
5. **Ошибка 5:** Отсутствует обработка случая когда avatar отсутствует
6. **Ошибка 6:** Некорректное условие для отображения статуса (всегда показывает "Online")
7. **Ошибка 7:** Неправильная логика отображения деталей
8. **Ошибка 8:** Отсутствует проверка на null для userDetails

### Ошибки в SCSS:
9. **Ошибка 9:** Неправильная вложенность для модификаторов в CSS Modules
10. **Ошибка 10:** Отсутствует fallback для ошибки загрузки изображения
11. **Ошибка 11:** Отсутствуют стили для offline статуса
12. **Ошибка 12:** Отсутствует обработка длинного текста (text-overflow)

## Задача 2: TodoList компонент

**Файлы:** `task2-todolist/TodoList.tsx`, `task2-todolist/TodoList.module.scss`

**Описание:** Список задач с фильтрацией, приоритетами и возможностью добавления/удаления.

### Ошибки в TypeScript/React:
1. **Ошибка 1:** Бесконечный цикл из-за `onTodosChange` в зависимостях useEffect
2. **Ошибка 2:** Отсутствует мемоизация для дорогой операции фильтрации
3. **Ошибка 3:** Функция `addTodo` создается заново при каждом рендере
4. **Ошибка 4:** Плохая генерация ID (Date.now() может дать дубликаты)
5. **Ошибка 5:** Функция `toggleTodo` не мемоизирована
6. **Ошибка 6:** Функция `deleteTodo` не мемоизирована
7. **Ошибка 7:** Отсутствует обработка edge cases (деление на ноль)
8. **Ошибка 8:** Кнопка Add не деактивируется когда input пустой
9. **Ошибка 9:** Обработчики фильтров создаются заново при каждом рендере
10. **Ошибка 10:** Не оптимизирована производительность списка (нужен React.memo)
11. **Ошибка 11:** Некорректное условие для отображения пустого состояния

### Ошибки в SCSS:
12. **Ошибка 13:** Не адаптивный дизайн для мобильных устройств
13. **Ошибка 14:** Отсутствуют стили для disabled состояния кнопки
14. **Ошибка 15:** Неправильная специфичность селектора для активного фильтра
15. **Ошибка 16:** Стили для completed состояния применяются некорректно
16. **Ошибка 17:** Отсутствуют цвета для разных приоритетов
17. **Ошибка 18:** Селекторы для приоритетов не работают с CSS Modules
18. **Ошибка 19:** Отсутствует иконка в пустом состоянии

21. **Ошибка 25:** Отсутствует обрезка длинного текста заголовка
22. **Ошибка 26:** Отсутствует focus состояние для кнопки закрытия
23. **Ошибка 27:** Не учитывается случай очень длинного контента
24. **Ошибка 28:** Отсутствует focus состояние для кнопок в footer
25. **Ошибка 29:** Отсутствует состояние loading для confirm кнопки

## Критерии оценки

### Отлично (Senior уровень):
- Найдены и исправлены все или почти все ошибки
- Предложены дополнительные улучшения
- Обоснованы архитектурные решения

### Хорошо (Middle+ уровень):
- Найдены и исправлены 70-85% ошибок
- Понимание принципов React и TypeScript
- Базовое понимание accessibility

### Удовлетворительно (Middle уровень):
- Найдены и исправлены 50-70% ошибок
- Базовые навыки отладки
- Понимание основ React hooks

### Неудовлетворительно:
- Найдено менее 50% ошибок
- Отсутствует понимание основных концепций
- Неспособность объяснить решения
