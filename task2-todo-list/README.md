# Задача 2: TodoList Component

## Описание
Компонент `TodoList` - это приложение для управления списком задач с приоритетами и фильтрацией.

## Найдите и исправьте следующие ошибки:

1. **TypeScript ошибка** - неправильный тип для id в интерфейсе Todo (строка 31)
2. **Логическая ошибка** - неправильное сравнение при удалении todo (строка 48)
3. **React ошибка** - использование индекса как key при рендере списка (строка 111)
4. **Ошибка с useEffect** - отсутствует проверка на undefined для onSave (строка 23)
5. **TypeScript ошибка** - неправильное приведение типа в onChange для select (строка 77)
6. **Ошибка с классами** - неправильное применение условного класса (строки 91, 96, 101)
7. **Логическая ошибка** - пустая форма все равно добавляет todo
8. **Проблема производительности** - сортировка выполняется при каждом рендере
