# Задача 3: SearchAutocomplete Component

## Описание
Компонент `SearchAutocomplete` - это поле поиска с автодополнением, поддержкой клавиатурной навигации и подсветкой совпадений.

## Найдите и исправьте следующие ошибки:

1. **Утечка памяти** - отсутствует зависимость в useEffect (строка 69)
2. **TypeScript ошибка** - возможный null при обращении к inputRef (строка 98)
3. **Ошибка обработки событий** - неправильный тип события для handleClickOutside (строка 36)
4. **Логическая ошибка** - onSelect может быть undefined (строка 107)
5. **Race condition** - при быстром вводе могут отображаться устаревшие результаты
6. **Проблема с регулярным выражением** - специальные символы в запросе ломают highlightMatch (строка 111)
7. **Ошибка доступности** - неправильная навигация с клавиатуры при пустых результатах
8. **Проблема производительности** - рендер подсветки происходит для всех результатов при каждом изменении

## Дополнительные улучшения (опционально):
- Добавить отмену предыдущих запросов при новом поиске
- Реализовать кэширование результатов
- Добавить индикацию минимального количества символов для поиска
- Улучшить обработку ошибок с retry логикой
- Добавить поддержку группировки результатов по категориям

## Ожидаемый результат:
Компонент должен стабильно работать, правильно обрабатывать все edge cases, быть доступным для screen readers и эффективно обновляться.
