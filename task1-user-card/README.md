# Задача 1: UserCard Component

## Описание
Компонент `UserCard` отображает карточку пользователя с информацией и действиями.

## Найдите и исправьте следующие ошибки:

1. **Ошибка с изображением** - компонент падает, если у пользователя нет аватара
2. **Ошибка с классами** - неправильное применение условных классов (строка 33)
3. **Утечка памяти** - после удаления компонент продолжает обновлять состояние
4. **TypeScript ошибка** - отсутствует обработка случая, когда роль пользователя может быть null
5. **Проблема с доступностью** - отсутствуют aria-labels для кнопок действий

## Дополнительные улучшения (опционально):
- Добавить обработку ошибок загрузки изображения
- Добавить анимацию при наведении на карточку
- Реализовать подтверждение удаления

## Ожидаемый результат:
Компонент должен корректно работать со всеми типами данных, быть доступным и не вызывать ошибок в консоли.
